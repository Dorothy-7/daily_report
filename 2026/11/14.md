## 分かったこと

- `document` はブラウザにしかない。Nodeで `script.js` を直接実行すると `document is not defined` になる
- `e.preventDefault()` がないと、フォーム送信でページが再読み込みされる
- タスクは文字だけでなく `{ id, text, done }` のオブジェクトで配列に入れる
- `nextId++` は「使ってから1増やす」。2回書くとidが飛ぶ
- 入力補完で `value` が `ariaValueMax` になっていた。動かないときはConsoleの赤いエラーを見る
- PRを作るには、先にmainへ1コミットしてpushしておく必要がある
- SQLは書く順番と、処理される順番が違う

| 書く順番 | 処理される順番 |
|---|---|
| SELECT | ① FROM |
| FROM | ② WHERE |
| WHERE | ③ GROUP BY |
| GROUP BY | ④ HAVING |
| HAVING | ⑤ SELECT |
| ORDER BY | ⑥ ORDER BY |

```sql
SELECT 商品名, COUNT(*) AS 件数
FROM test_table
WHERE 売上金額 >= 50000
GROUP BY 商品名
HAVING COUNT(*) >= 10
ORDER BY 件数 DESC;
```

1. FROM：`test_table` の全行を持ってくる
2. WHERE：売上金額が50000以上の行だけ残す
3. GROUP BY：残った行を商品名ごとにまとめる
4. HAVING：まとめた中で、行数が10以上のものだけ残す
5. SELECT：商品名と件数を表示用の列にする
6. ORDER BY：件数の多い順に並べる

- WHEREはまとめる前の行を絞る、HAVINGはまとめた後の結果を絞る
- `WHERE COUNT(*) >= 10` はエラー。WHERE（②）の時点ではまだまとめていないので数えられない
- `WHERE 件数 >= 10` もエラー。「件数」という名前はSELECT（⑤）で付けるので、②ではまだ存在しない
- `ORDER BY 件数` は書ける。ORDER BY（⑥）はSELECT（⑤）の後だから
- セミコロンは文の最後に1つだけ。途中に付けるとそこで文が終わる
- 記号（`=` `'` `( )`）は全部半角。日本語を打った直後に全角のまま打ちがち
- `AVG` `MAX` `MIN` は `AVG(売上金額)` のように列を指定する。丸めるときは `ROUND(AVG(売上金額))` と包む
- `.db` の拡張子を `.csv` に変えてもCSVにはならない。エクスポート機能で書き出す
- CSVの1行目が列名のときは、取り込みで Header をオンにする。忘れると列名をデータとして読んでエラーになる
- エラーは本文を読めば原因が書いてある（`invalid input syntax for type integer: "ID"` → 数値の列に文字を入れようとした）
