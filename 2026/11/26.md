## 取り組んだ課題一覧
- React講座：useStateでフォーム入力を扱う（UserForm）、配列のstateを更新する（updateUserName）

## 分かったこと
- つまずいていたのはReactというより、JavaScriptの省略した書き方だった
- `const { name, value } = e.target` は、打たれた入力欄から「どの欄か」と「打たれた文字」を取り出しているだけ
- `{ ...user, [name]: value }` は、今のuserを全部コピーして、打たれた欄だけ上書きしている
- `...user` を書かないと、他の項目が消える
- `onChange={onChange}` は左がinputの決まった名前、右が自分で作った関数。`()` を付けるとその場で動いてしまう
- 配列のstateは `map` で1人ずつ見て、idが合う人だけ書き換えたコピーにする

## ふかぼりする箇所
- 分割代入・スプレッド構文・`[ ]` でキーを指定する書き方
- `map` と三項演算子の組み合わせ
- type="number" でも `e.target.value` は文字列になる点
