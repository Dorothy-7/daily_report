## 学んだこと

### 1. 関数の書き方は4種類あるが、すべて同じ関数の別表記

```js
function greet(name) { return "こんにちは、" + name; }         // function宣言
const greet = function (name) { return "こんにちは、" + name; }; // 関数式
const greet = (name) => "こんにちは、" + name;                   // アロー関数
greet() { ... }                                                // オブジェクト内の省略記法
```

アロー関数は `function` を消して `=>` を入れた形。return 1行だけなら `{ }` と return も省略できる。

### 2. function とアロー関数は `this` の指す先が違う

```js
// function：this = 「.」の左のオブジェクト
const userWithFunction = {
  name: "Taro",
  greet: function () { console.log(`こんにちは、${this.name}です。`); },
};
userWithFunction.greet(); // "こんにちは、Taroです。"

// アロー関数：this = 外側（ブラウザなら window）→ window.name は ""
const userWithArrow = {
  name: "Jiro",
  greet: () => { console.log(`こんにちは、${this.name}です。`); },
};
userWithArrow.greet(); // "こんにちは、です。"
```

使い分け：オブジェクトのメソッドは function（または省略記法）、map / filter のコールバックはアロー関数。

### 3. スコープは `{ }` の入れ子で決まる

```js
const globalVariable = "G";
function checkScope() {
  const localVariable = "L";
  if (true) {
    const blockVariable = "B";
    console.log(localVariable);  // OK：内側から外側は見える
  }
  console.log(blockVariable);    // ReferenceError：外側から内側は見えない
}
console.log(localVariable);      // ReferenceError
```

ルールは1つ。「内側からは外側の変数が見える。外側からは内側の変数が見えない」。見えない変数を使うと `ReferenceError` になる。

## つまずいた点

- アロー関数の `=>` の右に `{ }` が無い書き方が、関数に見えなかった
- `this` が何を指すのか文章だけでは理解できず、「`.` の左のオブジェクト」という捉え方でようやく整理できた
- スコープは入れ子の図で見てイメージがついた
