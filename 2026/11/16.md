## 分かったこと

### ToDo List

- 「編集中かどうか」も `editing` として配列に持たせる。`done` と同じ発想
- `if(todo.editing){ }else{ }` で表示を出し分ける。文字を入力欄に変えるのではなく、作り直すときに入力欄を作っている
- 編集ボタンは `todo.editing = true`、保存ボタンは `todo.text` を書き換えて `false` に戻す
- `list.appendChild(li)` は `if / else` の後に1回書く
- `else` の中で作った `span` は、外では使えない（スコープ）
- GitHub Pagesは、リポジトリのHTML・CSS・JSをWebサイトとして公開できる。Settings → Pages でブランチを選ぶ
- `feature/todo` を指定すれば、マージせずにデプロイできる。pushするたびに自動で更新される

### SQL演習

- ターミナル（❯）とpsqlの中（bookhub=#）は別の場所。SQLはpsqlの中かファイルに書く。ターミナルに直接打つとzshのエラーになる
- psql -d bookhub -f ファイル名 は、先にファイルを作っておかないと動かない
- psql -l で表がずっと出続けるのはエラーではなく、qで抜けられる
- DUMP実行時のNOTICEはエラーではない（初回は消すテーブルが無いだけ）
- psql -d bookhub で中に入ると、SQLを打ってすぐ結果を見られる。\w ファイル名 で直前のSQLを保存できる
