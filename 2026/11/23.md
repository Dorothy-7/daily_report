## 分かったこと
- importとexportはセット。`export default` は `{ }` なし、`export const` は `{ }` ありで読み込む。混ぜると迷うので、どちらかに揃える
- `./` は同じフォルダ、`../` は1つ上。ファイルをフォルダに移したら、その分パスも変わる
- JSXの `{ }` の中にはJavaScriptの式を書ける。関数は `{getWeather()}` と `()` を付けて呼ぶ
- propsは親から子に渡す値。`({ name, role })` と書くと `props.` を付けずに使える
- 画面が真っ白になったら、まずブラウザのConsoleを見る。npm run devを止めていただけ、ということもあった
- REST APIは「何を」をURL、「どうする」をHTTPメソッドで表す約束事。movieなら一覧は `GET /movies`、1件は `GET /movies/{id}`、作成はPOST、更新はPUT、削除はDELETE
- サーバーは前のリクエストを覚えていないので、毎回必要な情報を送る

## ふかぼりする箇所
- `{ }` の3つの使い分け（importの `{ }`、JSXの `{ }`、分割代入の `{ }`）
- 相対パスの数え方。フォルダを移動したときに自分で直せるようにする
- PUTとPATCHの違い、ステータスコードの使い分け
