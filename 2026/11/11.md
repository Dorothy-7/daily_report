## 分かったこと
- `...` はスプレッドとレストの2つの意味がある。スプレッドは中身を広げる、レストは残りをまとめる。使うのはほとんど `{ ...user, age: 26 }` みたいにコピーして一部変えるやつ
- `const { id, name } = user` は、`user.id` と `user.name` をまとめて変数にする書き方
- クラスは constructor で `this.name = name` みたいに入れる。継承するときは extends を書いて、constructor の最初に super() を呼ぶ
- スプレッドでコピーするとメソッドは付いてこない
- export は2種類。名前付きは受け取るとき `{ }` で囲む。デフォルトは1ファイル1個で、受け取るとき `{ }` なし。デフォルトは「このファイルの代表」と思えばいい
- モジュールは HTML に `type="module"` が必要で、ダブルクリックでは動かない。Live Server で開く
- reduce は配列を順番に見て1つの値にする。for で書けることを短く書いているだけなので、自分で書くときは for でいい
- 配列の中のオブジェクトの値は `shoppingCart[0].price` みたいに2段階で取る。`shoppingCart.price` では取れない
- `(total, product)` の product は自分で付けた名前。配列にそんな文字は無い
- this を使わないメソッドなら、アロー関数で書いてもいい
- Set は重複が消える配列、Map は set で入れて get で取り出す箱
