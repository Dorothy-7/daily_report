### 分かったこと
- `fatal: not a git repository` は、そのフォルダで git init をしていない（または別フォルダにいる）ときに出る
- ssh-keygen の `-C` はただのコメントで、認証には影響しない。どのメールでも通る
- `ssh -T git@github.com` の初回確認は `yes` と3文字フルで打たないと `Host key verification failed` になる
- 「GitHub does not provide shell access」は成功時の正常なメッセージ
- `git branch -M main` は現在のブランチ名を main に強制変更するもの。GitHub側のデフォルトと揃えるために入れる
- `git remote add origin URL` は、リモートに origin というあだ名をつけて登録する。以後は URL の代わりに origin と書ける
- commit は手元に記録、push はその記録を GitHub に送る。commit しただけでは GitHub に何も反映されない
- `.gitignore` に書いたファイルは `git add .` しても追跡されない。`git check-ignore -v ファイル名` でどのルールで無視されたか確認できる
- `git switch -c ブランチ名` で新規ブランチ作成と移動が同時にできる（checkout -b と同じ）
- PRテンプレートは `.github/PULL_REQUEST_TEMPLATE.md` というパス・名前にすると GitHub が自動認識して本文に入る
- Reviewers に指定できるのはリポジトリにアクセス権がある人だけ
