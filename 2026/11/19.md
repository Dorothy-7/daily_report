## 分かったこと
- SQLの基本の並びは SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY
- ORDER BY は何も付けないと小さい順、DESC で大きい順。カンマで2つ目の並び順も指定できる
- LIKE '%SQL%' の % は「何文字でもよい」
- GROUP BY でまとめて COUNT や AVG で集計する。集計結果で絞るのは WHERE ではなく HAVING
- JOIN ... ON で別のテーブルを番号（author_id と id）でつなぐ。多対多は中間テーブルを挟んで JOIN を2回書く
- EXTRACT(YEAR FROM 日付) で年だけ取り出せる
- カッコやスペースが全角だとエラーになる。「以上」は => ではなく >=
- ターミナルの操作：Control + U で行を消す、バックスラッシュは Option + ¥、ページャーは q で抜ける
